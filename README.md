# SnapRedact (working name) — waitlist validation page

A planned browser extension: capture the page you are viewing locally, then one click detects and masks sensitive details (emails, phone numbers, names, amounts, order numbers) before you share the screenshot, plus searchable PDF export. Fully local — no account, no uploads. Planned $19 one-time.

- Validation page: https://alapha888.github.io/snapredact-waitlist/
- Status: product not built. This repo contains only the validation page — no product source code.
- Decision rule: registrations ≥20 by 2026-11-10 → start building (Edge Add-ons first, Gumroad license); below that, drop the idea and notify registrants by email. Additional differentiation check from the validation design: even at ≥20, if most registrants say Edge's built-in Web Capture is already enough, drop the idea. Registration email asks: what you most often mask, whether built-in Web Capture is enough, what you use today, whether you would pay $19 one-time.
- Indicative price (test parameter): $19 one-time. No payment taken, no pre-order.
- Demand evidence: extension category scan round 2, 2026-10-10 — GoFullPage ~11M Chrome users / ~4.9 rating, Premium ~$12/year with redaction and PDF export behind the paywall; Awesome Screenshot ~3–4M users, premium from ~$36/year. Counter-evidence recorded honestly: Edge ships free built-in Web Capture (capture + basic annotation), and both incumbents are already on Edge — the only wedge tested here is one-click auto-redaction as a standalone one-time purchase.
